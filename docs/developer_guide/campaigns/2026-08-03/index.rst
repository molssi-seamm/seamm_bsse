2026-08-03 -- N-fragment counterpoise architecture
=====================================================

Goal
----

Generalize the ORCA counterpoise (BSSE) correction from two fragments/
neutral-singlet-only to N fragments with independent per-fragment charge,
via a small engine-agnostic library (this package) plus a thin, generalized
substep inside ``orca_step``.
